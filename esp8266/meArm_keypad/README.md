# meArm 按键板（ESP8266，纯有线按键）

一块 ESP8266 + 4 个按键，替代 `others/f/MeArm/KeypadBoard_Task5` 那块"第二块 UNO + 按键"。
**没有 WiFi、没有网页、不用连互联网**：按下按键 → ESP 通过串口把单个字符发给机械臂。

```
  4 个按键 ──> ESP8266（消抖 + 单击/双击/三击判定） ──9600 8N1──> 机械臂 Uno
                        └── USB 串口 115200：调试输出（按了什么、发了什么、机械臂回了什么）
```

> 想要 WiFi 遥控（手机网页控制）的那份在上一层目录：`esp8266/README.md`（`meArm_wifi/meArm_wifi.ino`）。
> 两份程序互相独立，接线可以完全一样，按需烧其中一份即可。

## 1. 文件

| 文件 | 说明 |
|---|---|
| `meArm_keypad/meArm_keypad.ino` | 按键板主程序（只用 ESP8266 自带库，无第三方依赖） |

第 3 节状态 → 第 4 节收发 → 第 5 节按键消抖与连击判定 → 第 6 节 `setup/loop`。

## 2. 接线

**机械臂侧（Uno 的 D0/D1 就是那块按键板原来插的口）**

| 机械臂 Uno | ESP8266 (NodeMCU) | 说明 |
|---|---|---|
| D0 (RX) | D6 / GPIO12（TX） | 3.3V 直连可用（ATmega 的高电平门限约 3.0V） |
| D1 (TX, 5V) | D5 / GPIO14（RX） | **必须分压**：1kΩ 串联 + 2kΩ 到 GND，5V→3.33V |
| GND | GND | 必须共地，否则收到的全是乱码 |

**按键侧**（按键一端接引脚，另一端接 GND；用芯片内部上拉，不用外接电阻）

| 按键 | ESP8266 引脚 | 功能 |
|---|---|---|
| K1 | D1 / GPIO5 | 示教 / 记录点 |
| K2 | D2 / GPIO4 | 暂停 / 继续（单击/双击） |
| K3 | D7 / GPIO13 | 取消 / 折线 / 曲线（单击/双击/三击） |
| K4 | D3 / GPIO0 | 直线演示 / 基础图形（单击/双击） |

板载 LED（D4）每发一条命令闪一下，是"确实发出去了"的现场提示。

**四个注意**

1. **给机械臂烧录程序时，把 ESP 的 D6 那根线拔掉**（或给 ESP 断电）。Uno 的 D0 同时接在
   USB 转串口芯片上，两个驱动器抢一根线时 avrdude 会一直报
   `not in sync: resp=0x00`（实测踩过）。
2. **D3 是 GPIO0**：上电那一瞬间别按着 K4，否则 ESP 会进下载模式、机械臂收不到命令。
   按下瞬间的抖动由程序消抖，不用管。
3. ESP8266 峰值电流 300mA+，请用独立 AMS1117-3.3（输入输出各并 100nF + 470uF），
   不要用 Uno 的 3.3V 脚（只有约 50mA）。共地别忘。
4. 默认用 D5/D6 软串口跟机械臂通话，这样 USB 串口还能当调试口。想更保险（软串口在
   WiFi/中断多时可能丢字节，本程序不开 WiFi，9600 下很稳）就把 `ARM_LINK_SOFTWARE`
   改成 `0`，改用硬件串口 GPIO3(RX)/GPIO1(TX)——代价是 USB 调试口被机械臂占用。

## 3. 按键映射（和原按键板完全一致）

| 操作 | 发送 | 机械臂行为 |
|---|---|---|
| K1 单击 | `1` | 进入示教模式 / 记录一个示教点（已在示教则记录，最多 5 点） |
| K2 单击 | `2` | 暂停 |
| K2 双击 | `3` | 继续 |
| K3 单击 | `4` | 取消，回待机 |
| K3 双击 | `5` | 折线绘制（示教 ≥ 2 点） |
| K3 三击 | `6` | 曲线绘制（示教 ≥ 3 点） |
| K4 单击 | `7` | 直线演示（6 坐标） |
| K4 双击 | `8` | 基础图形（字母 N） |

参数沿用原按键板：消抖 `DEBOUNCE_MS = 30`、连击窗口 `CLICK_WINDOW_MS = 350`，
所以 `任务五_四按键使用说明.txt` 里的操作习惯照旧。

**想改按键或加按钮**：只改第 2 节的表格，例如给 K1 加个双击当"状态查询"：

```cpp
{ PIN_K1, 2, '?', "状态查询" },     // K1 双击
```

想多接一个按键：在配置区加 `#define PIN_K5 16`（D0/GPIO16 没有内部上拉，需要外接
10kΩ 上拉到 3.3V），再在表里加 `{ PIN_K5, 1, '?', "状态查询" }` 即可，程序会自动
把新引脚加入轮询（去重、最多 6 个键脚）。

## 4. 编译与烧录

**Arduino IDE**：开发板管理器装 "esp8266 by ESP8266 Community"（本机 3.1.1）→ 打开
`meArm_keypad/meArm_keypad.ino`（文件夹名必须等于文件名）→ 开发板选 **NodeMCU 1.0
(ESP-12E Module)** → 选 ESP 的 USB 口 → 上传。

**命令行**（本机实测）：

```powershell
$env:ARDUINO_DIRECTORIES_DATA="$env:LOCALAPPDATA\Arduino15"
& 'C:\Users\m2122\AppData\Local\Programs\arduino-ide\resources\app\lib\backend\resources\arduino-cli.exe' `
    compile --fqbn esp8266:esp8266:nodemcuv2 --warnings more 'D:\dsh1\meArm\esp8266\meArm_keypad'
```

实测占用：Flash 241 904 / 1 048 576 B（23%）、RAM 28 928 / 80 192 B（36%），**0 warning**。

## 5. 串口调试输出（115200）

接上 USB 打开串口监视器（115200）就能看到按键和机械臂的全过程：

```
=== meArm 按键板（ESP8266）===
机械臂串口：软串口 D5(RX)/D6(TX)，9600 8N1
按键： D5 D4 D13 D0  （另一端接 GND，内部上拉）
映射：K1×1=1 示教 | K2×1=2 暂停 K2×2=3 继续 | K3×1=4 取消 K3×2=5 折线 K3×3=6 曲线 | K4×1=7 直线 K4×2=8 字母N
< === Task5 轨迹绘制 ===
[键] 1 单击 → 示教/记录
> 1
< >>> 示教模式：笔尖已到起点(0,50)；摇杆移动笔尖，按键1单击记录（最多5点）；按键3双击=折线 / 三击=曲线
[键] 1 单击 → 示教/记录
> 1
[键] 1 单击 → 示教/记录
> 1
[键] 2 双击 → 曲线
> 6
< >>> 曲线绘制开始
```

`[键] …` 是判定结果，`> x` 是发给机械臂的字符，`< …` 是机械臂的回包（原样转发）。
按下没反应、或者机械臂不回话，看这一屏就能定位到"按键没读到"还是"串口没通"。

## 6. 已验证 / 未验证

* 已验证（编译）：arduino-cli 1.5.1 + esp8266 3.1.1，`--warnings more` 下
  **exit 0、0 warning 0 error**。
* 已验证（逻辑）：把 `keysTick()` 的消抖/连击判定逐行搬到 node 里跑合成波形，
  8 个场景全部符合预期 —— 四键各单击（`1` `2` `4` `7`）、双击（`3`）、三击（`6`）、
  两次单击间隔 700ms 会发两条 `2`、5ms 抖动 + 400ms 长按只算一次、K4 三击与 K2 三击
  提示"表里没有定义"、四键几乎同时按各自独立触发。
* 未验证（需要硬件）：与真实机械臂的串口收发、按键电气抖动、长时间运行。

## 7. 常见问题

| 现象 | 原因/处理 |
|---|---|
| 串口一堆乱码 | 没共地，或 ESP 收到的 5V 没分压（Uno D1 → ESP D5 必须 1kΩ+2kΩ） |
| 按了没反应，串口也没有 `[键]` | 按键接线错（要接引脚↔GND，用内部上拉）；或引脚被别的用途占了 |
| 有 `[键] …` 但没有 `> x` | 正常是同一行，若真没有就是 `ARM_LINK_SOFTWARE` 与实际接线不符 |
| 有 `> 1` 但机械臂没动 | 机械臂没在待机（正在绘制中会被忽略）、D0/D6 线没接好、或 ESP 上电时按着 K4 进了下载模式 |
| 双击变成了两条单击 | 两次按键间隔 > 350ms；`CLICK_WINDOW_MS` 可调大（比如 450） |
| 按键偶尔多触发一次 | 按键抖动太大：换质量好点的轻触开关，或在按键两端并 100nF 电容 |
| 给机械臂烧录失败 `not in sync: resp=0x00` | 拔掉 ESP 的 D6（D0 线）再烧 |
